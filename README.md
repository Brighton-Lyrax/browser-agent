# Browser Agent

Autonomous browser automation agent that mimics human-like actions with FastAPI and React.

## Features

- FastAPI backend for browser control
- React frontend for task management
- Human-like mouse movements and typing
- Screenshot capture and visual analysis
- Multi-tab support
- Task queue and execution history
- Plugin system for custom actions

## Tech Stack

- **Backend**: FastAPI, Python 3.11+
- **Frontend**: React, TypeScript, Vite
- **Automation**: Playwright / Puppeteer
- **AI**: OpenAI GPT-4o for decision making

## Getting Started

```bash
git clone https://github.com/Brighton-Lyrax/browser-agent.git
cd browser-agent
npm install
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
npm run dev
```
