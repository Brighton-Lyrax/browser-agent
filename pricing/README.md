# ReplyPilot Pricing

## Self-Hosted — Free
- Unlimited local leads
- Local follow-up queue
- Local revenue report
- Community support
- Best for hobbyists and internal tools

## Hosted — Subscription

### Hobby
Monthly: `$29/mo`  
Yearly: `$290/yr` (~$24/mo)
- 1,000 leads/mo
- 5,000 browser actions/mo
- Basic analytics
- Email support
- 1 project

### Pro
Monthly: `$149/mo`  
Yearly: `$1,490/yr` (~$124/mo)
- 25,000 leads/mo
- 50,000 browser actions/mo
- Advanced revenue attribution
- Priority support
- 10 projects
- API access

### Agency
Monthly: `$499/mo`
- 100,000 leads/mo
- 250,000 browser actions/mo
- Multi-project
- Team seats
- SLA + dedicated Slack
- Custom webhook routing

## Add-Ons
- Extra lead capacity: $0.05 / 1,000 leads
- Extra browser actions: $0.10 / 1,000 actions
- Premium support: $99/mo
- Custom onboarding: $500 flat

## Enterprise
- Custom onboarding + SLA
- Dedicated infra
- Contract terms available
- Email: operators@replypilot.io

## Bundled Templates
- Lead capture stack: included in Hobby+
- Support ticket bot: $49 one-time
- Marketplace monitor: $79 one-time
- Compliance scraper: $99 one-time

## Revenue Share
Self-host operators can enable payment processing via our hosted checkout bridge and split 70/30 operator/platform by default. Custom splits available for Agency partners.
