# FAQ

## What is ReplyPilot?
ReplyPilot is an open-source lead response and browser automation platform. It captures leads, replies fast, queues follow-ups, tracks revenue impact, and integrates with checkout flows.

## Can I self-host?
Yes. The default deployment is self-hosted with Docker Compose. You own the data and the runtime. Optional hosted plans remove infra burden.

## Which providers do you support?
PayPal is available now. Stripe, LemonSqueezy, Polar, and Gumroad support is provided via provider-ready checkout integrations in this repo.

## Do I need a browser driver?
The core lead-capture APIs do not require Playwright. Browser automation hooks are opt-in and require a compatible browser runtime.

## Is this GDPR compatible?
Self-hosted deployments can be configured for GDPR. Hosted plans include limited data retention controls and subject-request handling.

## How do I invite team members?
Agency plans include multi-project management and access controls.
